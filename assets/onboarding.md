# ALLOG 온보딩 화면 명세

## 목적

사용자가 ALLOG의 가치를 이해하고, 계정을 만든 뒤 개인화된 그룹 루틴 추천에 필요한 기본 정보를 입력하도록 돕는다.

## 전체 흐름

`시작 화면 → 로그인 → 본인인증 → 회원정보 입력 → 기본 정보 → 루틴 선호 → 응원 방식 → 생활 패턴 → 완료`

## 화면별 명세

### 1. 시작 화면

- 로고: `Anti Lazing Log`
- 메시지: **건강한 습관을 함께 만들어요.**
- 보조 문구: AI 기반의 맞춤형 루틴 추천 및 그룹과 함께하는 습관 형성
- 기본 동작: `시작하기`를 누르면 로그인 화면으로 이동
- 하단: 이미 계정이 있으면 `로그인`으로 이동

### 2. 로그인

- 입력: 아이디, 비밀번호
- 동작: `로그인` 버튼으로 인증 후 다음 단계 또는 홈으로 이동
- 보조 기능: 아이디·비밀번호 찾기, 회원가입
- 간편 로그인: 네이버, Apple, Google, 카카오

### 3. 본인인증

- 제목: **본인 확인을 위해 인증을 진행해 주세요.**
- 입력: 통신사 선택, 전화번호, 인증번호
- 동작: 개인정보 수집 및 이용 동의 후 `다음` 버튼 활성화

### 4. 계정 정보 입력

- 제목: **아이디와 비밀번호를 입력해 주세요.**
- 입력: 아이디, 비밀번호, 비밀번호 확인
- 검증: 아이디 중복 확인, 비밀번호 규칙 확인, 비밀번호 일치 여부
- 완료 시 `완료` 버튼으로 기본 정보 입력으로 이동

### 5. STEP 1 - 기본 정보

- 제목: **기본 정보를 입력해 주세요.**
- 입력: 닉네임, 성별, 생년월일, 키, 몸무게
- 성별: 여성 / 남성 / 선택 안 함
- 생년월일: 연·월·일 선택형 피커
- 동작: 필수 항목 입력 시 `다음 단계로` 활성화

### 6. STEP 2 - 루틴 선호

- 제목: **어떤 루틴을 개선하고 싶나요?**
- 선택 항목: 생활 패턴, 운동, 식사, 수면, 기타
- 동작: 최소 1개 선택 후 `다음` 활성화
- 탐색: `이전`으로 STEP 1로 돌아갈 수 있음

### 7. STEP 3 - 응원 방식

- 제목: **어떤 방식으로 응원받고 싶나요?**
- 캐릭터 선택: 콩콩이, 딸랑이, 북북이, 용이
- 각 캐릭터는 서로 다른 말투와 응원 스타일을 제공
- 동작: 하나 선택 후 `다음` 활성화

### 8. STEP 4 - 생활 패턴

- 제목: **생활 패턴을 알려주세요.**
- 입력 항목
  - 수면 시간: 취침·기상 시간 선택
  - 운동 빈도: 주 1회 / 주 2회 / 주 3회 / 주 4회 / 주 5회 / 거의 안 함
  - 식사 빈도: 매일 없음 / 1회 / 2회 이상
  - 선호 기간: 7일 / 14일 / 30일
- 완료: `다음`을 누르면 맞춤 그룹 추천 결과로 이동

### 9. 그룹 배정 완료

- 메시지: **환영합니다! 하트 3개를 받았어요.**
- 안내: 하트는 그룹 활동에 사용할 수 있음
- 표시: 그룹 참여를 통해 받을 수 있는 하트 기준 안내
- 동작: `홈으로 가기`

### 10. 최종 환영 화면

- 메시지: **환영합니다! 하트 3개를 받았어요.**
- 안내: 하트는 그룹 활동에 사용할 수 있음
- 동작: `홈으로 가기`

## 공통 UX 원칙

- 진행 단계 화면에는 STEP 표시와 진행 바를 제공한다.
- 이전으로 돌아가도 이미 입력한 값은 유지한다.
- 필수 입력값이 충족되기 전에는 다음 버튼을 비활성화한다.
- 선택형 카드는 선택 시 테두리와 배경색으로 상태를 명확히 표시한다.
- 오류는 입력 필드 바로 아래에 짧고 구체적으로 안내한다.
