1. 기업요구와서비스기회

AI·디지털 기술을 사용자의 일상 습관 형성과 반복 행동에 연결한다.

ALLOG는 건강·일상 루틴을 혼자 기록하는 데서 끝나지 않고, 다른 사람과 함께 수행하고 인증하며 지속하도록 만드는 그룹형 웰니스
경험을 제공한다. AAC 정형화 루틴은 제거하지만, 사용자의 실제 행동과 관련된 AAC 브랜드·서비스·혜택을 연결하는 사업 연계 구조는
유지한다.

  루틴 수행 데이터와 카테고리를 기반으로 관련 혜택을 자연스럽게 연결한다.

4. 최종서비스콘셉트

AI가 선택을 돕고, 사용자가 루틴방을 만들거나 참여하는 그룹형 웰니스 플랫폼.

서비스정의

ALLOG는 사용자의 기본 생활 패턴, 만들고 싶은 습관, 선호 기간을 바탕으로 AI     가 현재 모집 중인 기존 루틴방을 추천하고, 사용자가 추
천 또는 탐색을 통해 참가하거나 직접 새로운 루틴방을 생성해 다른 사람들과 함께 루틴을 수행하는 서비스다.

서비스작동원칙

  사용자는 기존 루틴방에 참가할 수도 있고 새로운 루틴방을 만들 수도 있다.
  AI 추천은 선택을 돕는 기능이며, 사용자는 “나중에 선택하기”를 통해 가입만 완료할 수 있다.
  모든 루틴방은 방장이 설정한 정원이 충족되면 시작한다.
  친구끼리 참여를 체크한 방은 비공개이며 초대링크를 통해서만 참가한다.
  공개 루틴방은 탐색 화면에 노출되어 다른 사용자가 직접 선택해 참가한다.
  인증·보상·신고·개인정보·의료 안전 원칙은 서비스 공통 정책으로 관리한다.

5. 루틴방구조

공개 루틴방과 친구끼리 비공개 루틴방을 하나의 생성 구조 안에서 관리한다.

5-1.      공개루틴방

방 만들기에서 “친구끼리 참여”를 체크하지 않은 기본 유형이다. 탐색 화면에 노출되며 사용자가 방의 카테고리, 핵심 루틴, 기간, 현재
인원을 확인한 뒤 직접 참가한다.

                                          방 생성

                                           ↓

                                       탐색 화면 노출

                                           ↓

                                      사용자 직접 참가

                                           ↓

                                         정원 충족

                                           ↓

                                         루틴 시작

5-2. 친구끼리비공개루틴방

방 만들기 페이지 하단의 “친구끼리 참여” 체크박스를 선택하면 비공개 방으로 생성된다. 방 생성 과정 마지막에서 초대링크를 제공하며
방장은 해당 링크를 공유해 팀원을 초대한다.

                                      친구끼리 참여 체크

                                           ↓

                                       비공개 방 생성

                                           ↓

                                       초대링크 발급

                                           ↓

                                       친구 링크 참가

                                           ↓

                                         정원 충족

                                           ↓

                                         루틴 시작

 •  추천 질문 예: “오늘 안 하면 어떻게 돼?”, “언제 하는 게 좋을까?”, “내가 완주할 수 있을까?”
탐색 - 루틴방 추천 코치

 •  온보딩의 기본 생활 패턴·만들고 싶은 습관·선호 기간을 기준으로 모집 중인 방을 추천한다.
 •  추천 이유를 설명하고 두 개 이상의 방을 부담도·기간·목표 적합도 기준으로 비교해준다.
 •  추천 질문 예: “나한테 가장 맞는 방은?”, “부담 적은 방 찾아줘”, “이 두 방 중 어디가 나아?”
그룹 상세 - 참가 판단 코치

 •  현재 생활 패턴과 방의 수행 빈도·기간을 비교하여 적합도와 부담도를 알려준다.
 •  방이 너무 어렵거나 쉬운 경우 대안이 되는 다른 루틴방을 안내한다.
 •  AI가 참가 여부를 대신 결정하지 않고 사용자가 판단할 수 있는 개인화된 맥락을 제공한다.
방 만들기 - 루틴 설계 코치

 •  카테고리와 사용자의 생활 패턴을 기준으로 수행하고 싶은 핵심 루틴 후보를 추천한다.
 •  사용자가 선택한 루틴의 빈도·기간이 과도한 경우 더 지속 가능한 범위로 조절하도록 제안한다.
